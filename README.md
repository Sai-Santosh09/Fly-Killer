# Fly Killer

A simple game where you tap or click to kill flies before they fly off screen. 

## how to use it

Just open and copy the `uri.text` in the dist folder and start swatting the flies!

## how it works

The flies move in the canvas element randomly and every 10 flies you kill the speed of flies is increased by 0.1x. The sound effect is generated by using Web Audio Api.

## building

If you want to run the build script:
npm install
node build.mjs
